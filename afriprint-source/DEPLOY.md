# Afriprint — deploying outside Lovable

This is the full source of the Afriprint site (sublimation + DTF printing). It is a
**TanStack Start** app (React 19 + Vite 8), which means it runs server code — the host
has to run a server, not just serve static files.

There is **no database, no login, and no secret keys** in this project, so you do not
need to configure any environment variables to deploy it.

## 1. Run it on your computer

You need Node.js 22 and either Bun or npm.

```sh
bun install      # or: npm install
bun run dev      # or: npm run dev
```

Then open the address the terminal prints.

## 2. Build

```sh
bun run build    # or: npm run build
```

The build uses Nitro, which packages the server output for whichever platform it detects.

## 3. Deploy

### A platform Nitro detects (Vercel, Netlify, Cloudflare Pages)

Push these files to a Git repository (GitHub, GitLab or Bitbucket) and connect it to the
platform. Then set:

- Build command: `npm run build`
- Node.js version: **22**
- Publish / output directory: `dist` (needed on Netlify and Cloudflare Pages; Vercel needs none)

Every push to the deployed branch triggers a new deployment.

### Your own server or a container

Build with the Node.js server preset and run the output:

```sh
NITRO_PRESET=node-server npm run build
node .output/server/index.mjs
```

The server listens on port `3000` (set `PORT` and `HOST` to change that). Put your reverse
proxy in front of it and handle HTTPS there. The server handles routing itself, so do not
add an `index.html` fallback rule.

## 4. Check it before going live

- `npm run test` passes
- The home page renders in the browser and the page text is visible in view-source (server rendering works)
- Move the mouse: the yellow pointer dot with its trailing ring, the paint-splatter drops, the card tilt, and the spotlight that follows the cursor

## Where things live

| File | What it holds |
| --- | --- |
| `src/routes/index.tsx` | The whole page — sections, services, gallery, process steps, contact details, and all the mouse effects (custom cursor, splatter, tilt, spotlight) |
| `src/routes/__root.tsx` | Page shell: title, description, social-sharing preview tags, fonts |
| `src/styles.css` | Colour scheme (black, yellow, orange), fonts, Tailwind theme |
| `src/assets/hero.jpg` | AI-generated shirt + cap picture — replace with your own photos |
| `public/favicon.ico` | Browser tab icon |
| `public/robots.txt` | Search-engine rules |
| `src/components/ui/` | shadcn UI building blocks (mostly unused by this page) |
| `src/routeTree.gen.ts` | Generated by the router plugin — do not edit by hand |
| `src/server.ts`, `src/start.ts` | Server entry and request middleware |
| `vite.config.ts` | Build config (Nitro target, path alias) |

## Editing the content

Prices, the WhatsApp number (`081 233 5189`), email, address and section copy all sit in
`src/routes/index.tsx` as plain text — search for the word you want to change.
